# LoL Item-Verification Suspension — 2026-08-05

**Status:** Active until explicit user restoration  
**Authority:** LoL v0.3.28  
**Reason:** Phone screenshots do not reliably capture item states.

## Operating rule

Item verification is not a mandatory input for LoL verdicts while this suspension is active.

Do not request item screenshots as a standard prerequisite. Do not delay a live response solely because items are missing, cropped, unreadable, or absent from the supplied interface.

## Required behavior

- Treat unknown items as neutral.
- Never guess item names or breakpoints.
- Never count an assumed item as confirmation.
- Remove item-dependent reasoning from the thesis.
- Use synchronized scoreboard state, objective inventory, role gold, K/D/A function, execution conversions, draft access/protection, and exact market data.
- Keep all normal odds, exposure, placement, expiry, repair, anti-line-chasing, and market-family gates.

## Item-dependent pass condition

Use:

`NO BET — THESIS DEPENDS ON UNVERIFIED ITEMS`

only when the market cannot be justified without a specific unknown item condition. Missing items alone are not a pass condition.

## Phone-compatible screenshot request

For live analysis, prioritize:

- game and side identity;
- exact clock;
- kills and gold direction;
- role-gold deltas when available;
- towers and inhibitors;
- dragons, soul point, Grubs, Herald, Baron, and Elder;
- K/D/A;
- current odds and line status.

## Restoration

This suspension remains active across matches and chats. It ends only after the user explicitly requests restoration and the active model state is updated.
