# Model Changelog — LoL v0.3.14

**Effective:** 2026-08-01 21:09 UTC+7

## Trigger

Review of DK vs Gen.G Game 2 and BLG vs JDG Game 2 found that live assessments did not consistently inventory completed items, meaningful components, item concentration, unspent gold, or damage-versus-durability breakpoints.

## Changes

- Added a mandatory post-recall item inventory in Top / Jungle / Mid / ADC / Support order.
- Distinguished raw gold from currently usable combat strength.
- Required item-qualified confirmation before calling damage, waveclear, frontline, engage, scaling, objective damage, or one-fight close potential functional.
- Added damage-versus-durability comparison for kill markets and fight-lethality projections.
- Prohibited kill-Over leans from draft engage density alone.
- Added item-distribution checks for moneylines, kill handicaps, kill totals, and duration markets.
- Added item completion, substantial recall spending, defensive-active purchases, and relevant level breakpoints as expiry events.
- Added an unknown-item veto: no official post-recall live recommendation when relevant item state cannot be read.

## Attribution

No official P/L or probation result changed. This is a process-rule update. The user-defined probation remains 4/10, 1-3, -601,250 VND (-0.60125u).

## Review threshold

Review after five fully graded live assessments using the required item block or after completion of the ten-wager probation, whichever occurs first.
