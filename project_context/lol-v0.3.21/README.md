# LoL Live Betting Context v0.3.21

Canonical model source: `MODEL_RULES_LOL_V0.3.21.md`.

Primary change from v0.3.20:

- recognize favorite kill-margin expansion created by distributed economy and structural compression;
- upgrade converted Grubs into hard structural acceleration only after tower or lane-access conversion;
- distinguish stabilizing fight avoidance from compressive avoidance;
- prevent low mid-game kill pace from producing false kill-Under confidence when late forced fights remain;
- select a controlled favorite handicap line rather than rejecting the entire negative-handicap ladder or chasing an excessive line.

The v0.3.19 positive-underdog anti-line-chasing controls and all stricter v0.3.20 rules remain active.
