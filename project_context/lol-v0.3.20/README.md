# LoL Live Betting Context v0.3.20

Canonical model source: `MODEL_RULES_LOL_V0.3.20.md`.

Primary changes from v0.3.19:

- exact separation of `LEAN`, `WATCH ONLY`, and `FORCED PICK`;
- mandatory verification of which team produced intervening live-state changes;
- objective-conflict and protected-carry checks for moneylines;
- stricter lineup and Game 1 draft requirements for series -1.5 map spreads;
- one lean-only repaired-watch pathway for genuinely restored positive-handicap theses;
- one-line kill-Under selection with timing and safety-buffer requirements.

The v0.3.19 anti-line-chasing veto remains active. Official placement, bankroll, and probation controls are unchanged.
